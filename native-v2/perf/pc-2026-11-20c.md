# The chat log as one element per block, 20 Nov 2026 (farhan-RP-15)

F31, round 6. Each of Claude's blocks is now a single element: `BlockEl`
for a paragraph, heading, quote, list item or rule, and `TableEl` for a
table. Each is laid out once per width, with no taffy subtree, and only
painted while the log scrolls. Each log is painted in one layer, and a
line's glyphs go straight into that layer (ARCHITECTURE.md, "Virtualised
lists"). Measured on the PC's own display (Wayland, AMD Renoir, the window
1920x1040), release build, `ZED_MEASUREMENTS=1`. One window at a time,
each closed by its PID, with a fresh config folder and no owner sign-in.

## The client, tools/measure-pc.mjs

The test server is `tools/stub-server.sh 4884` on the PC: a bare server
whose `claude` is `tools/claude-stub.mjs`, so the owner's Claude was never
used. It streams the replies at about 600 characters a second. The scene:
four seeded chats (a 300-item list, long markdown with tables and code, a
120-item list, a long article), and a fifth that streams while the wheel
sweeps.

## What did it, step by step (chatlog5 p95 on the display)

| step | p95 |
|---|---|
| round 5: slimmer div rows | 9.3–10.3 |
| BlockEl: paragraphs, headings, quotes, items, rules as one element each | 8.5 |
| one paint layer per row | 7.6–7.9 |
| one paint layer per log instead | 7.0–7.2 |
| no background pass where nothing has a background | 6.4–6.8 |
| TableEl: tables as one element | 6.0–6.1 |
| the line's glyphs painted into the log's layer (no layer per line) | 5.7–5.9 |

## The same look, checked

Every step was compared pixel for pixel with the div version (the run's
HEAD log.rs), headless under Xvfb (`crundi-v2-floor`, ffmpeg x11grab). The
checks covered one pane and five panes, at window widths 1920, 1777 and
1503, at the tail and scrolled up twice, and a drag selection. All were
identical. test/log-element.mjs (18 checks: hits, drag, Ctrl+C, a
selection kept across a scroll, double- and triple-click, click to
clear, shift-click and extend (F25), a link click, streaming, idle) passes.
test/slice.mjs against the stub server passed 39 of 41 here. The two
misses are its picture diffs: ImageMagick is not installed on this PC.

Profiles (gdb, perf/gdb-sample.py) are not kept: they guided each step,
and the table above is what they bought.
